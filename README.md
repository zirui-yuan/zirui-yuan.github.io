# Zirui Yuan (袁子瑞) — Personal Academic Homepage

Static personal homepage hosted at [https://zirui-yuan.github.io](https://zirui-yuan.github.io).

## Structure

- `index.html` — Main single-page academic homepage (Bio, News, Publications, Experience, Education, Honors).
- `styles.css` — Editorial typography, light/dark theme tokens, responsive layout, and print styles.
- `script.js` — Theme switcher, publication filters, inline Abstract & BibTeX drawers, copy-to-clipboard actions, and scroll-spy navigation.
- `images/` — Profile portrait and custom SVG/ICO favicons.
- `files/` — Downloadable CV PDF.
- `.nojekyll` — Direct static serving on GitHub Pages with zero build step.

## Local Preview

```bash
python3 -m http.server 4173
```

Then open [http://localhost:4173](http://localhost:4173).
